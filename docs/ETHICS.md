# 倫理ガイドライン

動作評価AIシステムの安全な運用のためのガイドラインです。

## 基本方針

このシステムは**教育目的**で開発されており、以下の原則に基づいて運用されます：

### 1. 医学的診断ではない

- AIの評価は**参考情報**であり、医学的診断ではありません
- 身体的な問題が疑われる場合は、専門家に相談してください
- システムは「良い・悪い」の判定を行うものではありません

### 2. 自己比較のための指標

- 点数は**他者との比較**ではなく、**自己の振り返り**のための指標です
- 同じ動作を繰り返し評価し、変化を観察することで学習効果が高まります
- 点数の変動に一喜一憂せず、長期的な視点で活用してください

### 3. 最終判断は人間が行う

- AIのフィードバックは参考情報として活用してください
- 動作の改善や指導は、教員・指導者・専門家と相談の上で行ってください
- 評価結果だけで判断せず、総合的な視点を持ってください

## 禁止事項

### システム設計上の禁止

以下の用語・表現はシステム内で使用されません：

| 禁止用語 | 理由 |
|---------|------|
| 診断 | 医療行為を示唆するため |
| 異常・正常 | 医学的判断を示唆するため |
| 疾患・障害 | 病気や障害の存在を断定するため |
| 治療 | 医療行為を示唆するため |
| 〜すべき | 断定的で押し付けがましいため |

### 運用上の禁止

- 評価結果を成績評価の唯一の根拠として使用すること
- 学生間での点数比較や序列化を行うこと
- 評価結果のみを根拠に身体的問題を指摘すること

## 推奨される活用方法

### 教育現場での活用

1. **自己観察の補助**: 自分の動きを客観的に振り返るツールとして
2. **言語化の練習**: 動作の特徴を言葉で説明する練習として
3. **改善目標の設定**: 具体的な改善ポイントを見つけるために
4. **学習の記録**: Before/After の比較資料として

### フィードバックの伝え方

教員・指導者がこのシステムを使用する際：

- 「AIは〜と観察していますが、どう思いますか？」と対話のきっかけに
- 「点数は参考程度に、自分で感じた違いを大切にしてください」
- 「改善フィードバックの中で、取り組みやすそうなものを選んでみましょう」

## 免責事項

- 本システムの評価結果に基づく行動については、利用者の責任において行ってください
- 身体的な痛みや違和感がある場合は、本システムの使用を中止し、医療専門家に相談してください
- システムの評価結果は、AIによる推定であり、完全な正確性を保証するものではありません

---

**開発思想**: このシステムは、AIが人を評価するものではありません。AIを使って、人が「動きを考え、言語化し、改善する」ための教育システムです。
