# 動作評価AIシステムを活用した授業構成案

## 授業概要

| 項目 | 内容 |
|-----|------|
| **授業名** | 基本動作の評価とフィードバック指導 |
| **対象** | 運動指導者・トレーナー養成課程の学生 |
| **目的** | スクワット・歩行動作を評価し、クライアントに適切なフィードバックができるようになる |
| **所要時間** | 90分（または2コマ） |
| **使用ツール** | 動作評価AIシステム（https://sqandwalk.pages.dev） |

## 1. 導入・講義（15分）

### 学習目標の提示
- 動作評価の目的と意義を理解する
- 「良い・悪い」ではなく「観察と気づき」の視点を持つ
- クライアントへのフィードバック方法を学ぶ

### 動作評価の基本概念
- **動作評価とは**: 動きのパターンを観察し、改善点を見つけるプロセス
- **評価の目的**: 診断ではなく、教育的フィードバックのため
- **AIの役割**: 客観的な観察の補助ツールとして活用

### 本システムの説明
- 動画アップロード → フレーム抽出 → AI分析 → フィードバック
- 4つの評価観点 × 5段階評価
- 「参照フレーム」で根拠を明示

> **強調ポイント**: AIの評価は「参考情報」であり、最終判断は指導者が行う

---

## 2. 評価観点のポイント説明（10分）

### スクワット（前方視点）の評価観点

| 観点 | 主な観察ポイント |
|-----|-----------------|
| **膝関節外反（Knee Valgus）** | 膝が内側に入っていないか、Q角の変化 |
| **荷重分布** | 骨盤・肩の水平性、左右への重心偏位 |
| **体幹側方偏位** | 脊柱の側屈、肩甲骨の高さの左右差 |
| **足部アーチ制御** | 回内（pronation）、母趾球への過度な荷重 |

### スクワット（側方視点）の評価観点

| 観点 | 主な観察ポイント |
|-----|-----------------|
| **ヒップヒンジ** | 股関節屈曲と体幹前傾のバランス |
| **膝関節軌道** | 膝の前方移動量、脛骨角度（15-25度目安） |
| **脊柱アライメント** | 腰椎前彎の維持、丸背の有無 |
| **深さと動作制御** | 目標深度、動作の滑らかさ |

### 歩行動作の評価観点

| 観点 | 主な観察ポイント |
|-----|-----------------|
| **初期接地** | 踵からの接地（heel strike）、膝の軽度屈曲 |
| **立脚中期安定性** | 骨盤の水平性（トレンデレンブルグ徴候なし） |
| **蹴り出し** | 足関節底屈による推進力、母趾での蹴り出し |
| **腕振りと協調性** | 対側パターン、振幅の適切さ |

## 3. 【実習①】AIシステムで初回評価（15分）

### 実習の進め方

1. **ペアまたはグループを作る**（2〜3人）
2. **動画撮影**
   - スクワット：前方・側方の2パターン
   - 歩行：側方から撮影
3. **システムにアップロード**
   - https://sqandwalk.pages.dev にアクセス
   - 動作種別を選択 → 動画をアップロード → 評価開始
4. **結果を記録**
   - 各観点のスコアをワークシートに記入
   - 気になるフィードバックをメモ

## 4. スクワット：詳細解説と指導ポイント（15分）

### 膝関節外反（Knee Valgus）

**メカニズム**
- 股関節内転・内旋 + 膝関節外反 + 足関節回内 が連動
- 主な原因: 中殿筋・外旋筋群の筋力低下、股関節可動域制限

**観察のコツ**
- 下降相の中間〜最下点で最も顕著に現れる
- 膝蓋骨と第2趾の位置関係を確認

**指導のポイント**
- 「膝を外に向けて」という指示は過剰代償を生む可能性
- 「両膝の間にボールを挟むイメージ」で内側への意識を防ぐ
- ミニバンドを膝上に装着して抵抗を加える

**改善エクササイズ**
1. クラムシェル（側臥位での股関節外旋）
2. モンスターウォーク（ミニバンド歩行）
3. シングルレッグスクワット（低負荷から）

---

### ヒップヒンジ

**メカニズム**
- 股関節屈曲を主動力とした動作パターン
- 「椅子に座る」動作の基本

**観察のコツ**
- 臀部の後方移動が先行しているか
- 体幹と大腿の角度関係

**指導のポイント**
- 「お尻を後ろに引く」という言語cue
- 壁に背を向けて立ち、お尻で壁をタッチする練習
- ダウエルロッド（棒）を背中に当てて3点接触を維持

**改善エクササイズ**
1. ヒップヒンジドリル（ダウエルロッド使用）
2. グッドモーニング（軽負荷）
3. ルーマニアンデッドリフト

---

### 脊柱アライメント

**メカニズム**
- 腰椎前彎の維持 = 脊柱起立筋・多裂筋の等尺性収縮
- 丸背（butt wink）= 股関節可動域の限界で骨盤後傾

**観察のコツ**
- 最下点付近で腰椎のカーブが失われていないか
- 胸椎の過度な後彎がないか

**指導のポイント**
- 「胸を張る」「視線は前方やや上」
- 深さを制限して良好なアライメントを優先
- 足幅やつま先の向きを調整

**改善エクササイズ**
1. キャット&カウ（脊柱可動性）
2. デッドバグ（体幹安定性）
3. ゴブレットスクワット（カウンターバランス）

---

## 5. 歩行動作：詳細解説と指導ポイント（15分）

### 初期接地（Initial Contact）

**正常パターン**
- 踵から接地（heel strike）
- 膝関節は軽度屈曲位（約5度）
- 股関節は屈曲位（約25度）

**観察のコツ**
- 足底全体での接地（flat foot）になっていないか
- つま先からの接地（toe strike）がないか

**指導のポイント**
- 「踵から着地する」意識
- 過度なストライド（歩幅）を避ける
- 前脛骨筋の強化

**改善エクササイズ**
1. ヒールウォーク
2. 足関節背屈ストレッチ
3. ステップ練習（意識的な踵接地）

---

### 立脚中期安定性（Midstance Stability）

**正常パターン**
- 骨盤は水平を維持
- 体幹の側方動揺なし
- 中殿筋による片脚支持の安定

**観察のコツ**
- 遊脚側への骨盤下制（トレンデレンブルグ徴候）
- 体幹の側屈による代償

**指導のポイント**
- 股関節外転筋群の強化が最優先
- 片脚立ちバランス練習
- ゆっくり歩く練習で安定性を意識

**改善エクササイズ**
1. サイドライイングヒップアブダクション
2. 片脚立ち（目開き → 目閉じ）
3. ラテラルバンドウォーク

---

### 蹴り出し（Push-off）

**正常パターン**
- 足関節底屈による推進力生成
- 股関節伸展（約10度過伸展）
- 母趾での力強い蹴り出し

**観察のコツ**
- 足関節の底屈が不十分でないか
- 股関節伸展制限による歩幅短縮がないか

**指導のポイント**
- 「最後まで蹴り切る」意識
- 下腿三頭筋・腸腰筋の柔軟性確保
- カーフレイズの実施

**改善エクササイズ**
1. カーフレイズ（両脚 → 片脚）
2. 股関節屈筋ストレッチ
3. パワーウォーク（意識的な蹴り出し）

---

### 腕振りと協調性

**正常パターン**
- 対側パターン（右脚前進時に左腕前方）
- 自然でリラックスした振り幅
- 肩甲帯の自由な動き

**観察のコツ**
- 腕振りの消失や極端な左右差
- 肩の緊張による振りの硬さ

**指導のポイント**
- 「腕は力を抜いて自然に」
- 過度な意識は逆効果になることも
- 体幹回旋との連動を意識

**改善エクササイズ**
1. 腕振りウォーク（誇張した動作）
2. 体幹回旋ストレッチ
3. クロスボディマーチ

---

## 6. 【実習②】修正後の再評価（15分）

### 再評価の進め方

1. **初回評価で見つかった課題を確認**
2. **1〜2つの改善ポイントに絞る**
   - 例: 「膝関節外反を改善するため、膝を外に意識」
3. **短時間の練習・修正**（5分程度）
4. **再度動画撮影 → AIシステムで再評価**
5. **初回との比較**

### 比較のポイント

- スコアの変化（上がった/下がった/変化なし）
- フレーム参照の変化
- 自覚的な感覚の変化

### ディスカッション

- 「どの観点が改善したか？」
- 「AIのフィードバックと自分の感覚は一致したか？」
- 「クライアントにどう伝えるか？」

---

## 7. まとめ・振り返り（5分）

### 本日の学びの確認

1. **評価の視点**
   - 4つの観点から動作を分解して観察できる
   - フレームごとの観察ポイントを理解した

2. **フィードバックのポイント**
   - 「良い・悪い」ではなく「気づき」を伝える
   - 改善策は具体的なエクササイズとセットで
   - スモールステップで変化を実感させる

3. **AIツールの活用**
   - 客観的な視点を補助するツールとして
   - 最終判断は指導者が行う

### 次回への課題

- 自分自身の動作を撮影し、評価・改善に取り組む
- 家族や友人をクライアントに見立てて練習

## 授業運営のヒント

1. **動画撮影の環境**
   - 明るい場所で撮影（逆光を避ける）
   - 背景がシンプルな場所
   - 全身が映るカメラ位置

2. **Wi-Fi環境の確認**
   - 多人数が同時アクセスする場合、回線速度を確認

3. **グループ編成**
   - 2〜3人がベスト（撮影者・被験者・記録者）

4. **時間管理**
   - 動画撮影に時間がかかりがちなので、タイマーを設定
